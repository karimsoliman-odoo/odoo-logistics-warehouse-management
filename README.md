# Odoo Logistics & Warehouse Management

A professional Odoo portfolio project for logistics and warehouse operations, designed to demonstrate practical Odoo development skills across shipment tracking, storage billing, outbound operations, workflow control, security, and reporting.

## Target Version
- Odoo 20.0
- Community / Enterprise compatible design

## Planned Features
- Shipment registration and tracking
- Customer and reference management
- Entry and exit dates
- Quantity and CBM tracking
- Storage duration calculation
- Storage billing calculation
- Shipment status workflow
- Outbound operations
- User / Manager access control
- Printable reports
- Demo data and automated tests

## Technical Skills Demonstrated
- Odoo ORM models
- Computed fields
- Constraints and business logic
- XML views and menus
- Security groups and access rights
- Reports
- Modular architecture
- Git / GitHub workflow
- Upgrade-friendly custom development

## Project Structure

## Development Principle
This project is built as an independent custom module without modifying Odoo core, with portability and future upgradeability in mind.
